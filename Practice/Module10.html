Part A: Design, hypotheses, and ANOVA structure

Q1

What does a two-way ANOVA with replication test for Factor A (sunlight) and Factor B (watering)?

  1. Only the two main effects
  2. The main effect of A, the main effect of B, and the A × B interaction
  3. Only whether all 8 cell means are equal
  4. Only the A × B interaction

Answer: B.

Justification: The note sets up three pairs of hypotheses: main effect of A, main effect of B, and the interaction.

Why the others are wrong: A omits the interaction, which replication makes testable. C is a single global test, which is not how the two-way table is organized. D leaves out the main effects.
Q2 
> table(growthData$sunlight, growthData$watering)

         Daily Weekly
  High       5      5
  Low        5      5
  Medium     5      5
  None       5      5

What does this show?

  1. An unbalanced design with 8 replicates per cell
  2. An unbalanced design with N = 40
  3. A design with a = 2 sunlight levels, b = 4 watering levels, and 10 per cell
  4. A balanced design with a = 4, b = 2, 5 replicates per cell, and N = 40

Answer: D.

Justification: The table has 4 sunlight rows × 2 watering columns = 8 cells, each containing 5 plants, so N = 8 × 5 = 40. The note describes this as a balanced design with replications.

Why the others are wrong: A and B contradict the equal cell counts, since every cell has 5, so the design is balanced. A also gives the wrong number of replicates (8 cells × 8 = 64 ≠ 40). C swaps the factors and miscounts the cell sizes.
Q3 
> a <- 4; b <- 2; N <- 40
> c(A = a-1, B = b-1, AB = (a-1)*(b-1), E = N - a*b, T = N - 1)
 A  B AB  E  T
 3  1  3 32 39

What is the correct degrees of freedom for the interaction, and how can you check it?

  1. (a − 1)(b − 1) = 3. The components 3 + 1 + 3 + 32 add up to the total df of 39
  2. (a − b)(b − 1) = 2, as printed in the note's df list
  3. a × b = 8
  4. a + b − 2 = 4

Answer: A.

Justification: The note's own check says N − 1 = (a − 1) + (b − 1) + (a − 1)(b − 1) + (N − ab). With a = 4, b = 2, N = 40 this gives 39 = 3 + 1 + 3 + 32. The "(a − b)" in the note's df list is a typo for (a − 1).

Why the others are wrong: B would give 3 + 1 + 2 + 32 = 38, not 39, so the identity fails. C is the number of cells, not a df. D is a coincidental expression that does not match the formula.
Q4

Which statement gives the correct test of the sunlight (Factor A) main effect?

  1. FA = MSA/SSE ~ F(a − 1, N − ab)
  2. FA = SSA/SSE ~ F(3, 32)
  3. FA = MSA/MSE ~ F(a − 1, N − ab) = F(3, 32), and FA = 6.255/0.271 ≈ 23.05
  4. FA = MSA/MSB ~ F(3, 1)

Answer: C.

Justification: Each F statistic in the note divides a mean square by the error mean square, as FB = MSB/MSE does. For sunlight the df are (a − 1, N − ab) = (3, 32), and 6.255/0.271 = 23.05 matches the R output. The note's printed "MSA/SSE" is a typo.

Why the others are wrong: A divides by a sum of squares, which is not on the mean-square scale. B ignores df entirely. D uses the watering mean square as the denominator, but all main-effect and interaction tests share MSE.
Q5

Given only the first two columns of the table (Df and Sum Sq), you derive the rest in R.

> MSE   <- 8.684/32
> MS.AB <- 1.011/3
> F.AB  <- MS.AB/MSE
> F.AB
[1] 1.241824
> pf(F.AB, 3, 32, lower.tail = FALSE)
[1] 0.3107921

What do the results tell us about the A × B interaction?

  1. F = 0.337 and p < 0.001, so the interaction is significant
  2. F ≈ 1.24 with p ≈ 0.31, so there is no significant interaction at α = 0.05
  3. F ≈ 1.24 with p ≈ 0.031, so the interaction is significant
  4. F ≈ 3.73 with p ≈ 0.021, so the interaction is significant

Answer: B.

Justification: The note says to build the remaining columns from Df and Sum Sq using pf(F, df1, df2, lower.tail = FALSE). MSAB = 1.011/3 = 0.337, MSE = 8.684/32 = 0.2714, F = 1.24, df = (3, 32), and p = 0.31 > 0.05.

Why the others are wrong: A reports MSAB as the F value. C has a decimal slip in the p-value. D comes from dividing SSAB by MSE without dividing by its df (1.011/0.2714 = 3.73), which is a common error.
Q6

The table shows SST = 28.460, SSA = 18.765, SSB ≈ 0.000, and SSAB = 1.011. What is SSE?

> 28.460 - 18.765 - 0.000 - 1.011
[1] 8.684
  1. 48.236
  2. 19.776
  3. 0.271
  4. 8.684

Answer: D.

Justification: SST = SSA + SSB + SSAB + SSE, so SSE = 28.460 − 18.765 − 0.000 − 1.011 = 8.684, which matches the Residuals row.

Why the others are wrong: A adds SST to the explained sums of squares. B is the sum of the explained SS (SSA + SSB + SSAB). C is MSE = SSE/32, a mean square, not a sum of squares.

Part B: Data preparation and ANOVA output in R

Q7

The wide data were stacked as growth <- c(None, Low, Medium, High), each of 10 values (the first 5 Daily, the last 5 Weekly).

watering <- rep(c(rep("Daily", 5), rep("Weekly", 5)), 4)
> length(watering)
[1] 40
> head(watering, 12)
 [1] "Daily"  "Daily"  "Daily"  "Daily"  "Daily"  "Weekly" "Weekly" "Weekly"
 [9] "Weekly" "Weekly" "Daily"  "Daily"

Why is this correct?

  1. The inner rep() builds the 10-value pattern (5 Daily, 5 Weekly), and the outer rep(..., 4) repeats it once for each sunlight column
  2. It should use times = 40 so each label appears 40 times
  3. It should use each = 4 to separate the sunlight levels
  4. It is wrong, because label vectors must have length 10

Answer: A.

Justification: The note says the inner rep() returns the pattern for the first column and the outer rep() replicates it for the rest. The result lines up with the stacked growth vector, 40 labels for 40 values.

Why the others are wrong: B would produce a vector of length 400 and would not match the data. C would repeat each label 4 times in a row and would not align with the stacked data. D is false, since the long format needs one label for every observation (length 40).
Q8 
> summary(growth.aov)
                  Df Sum Sq Mean Sq F value  Pr(>F)
sunlight           3 18.765   6.255  23.049 3.9e-08 ***
watering           1  0.000   0.000   0.001   0.976
sunlight:watering  3  1.011   0.337   1.242   0.311
Residuals         32  8.684   0.271

Which conclusion is correct at α = 0.05?

  1. Only watering has a significant effect
  2. All three effects are significant
  3. Sunlight has a significant main effect, and there is no evidence of a watering main effect or an interaction
  4. The interaction is significant because its F value exceeds 1

Answer: C.

Justification: The sunlight p-value (3.9e-08) is below 0.05, while watering (0.976) and the interaction (0.311) are above it.

Why the others are wrong: A reverses the results. B ignores the two large p-values. D uses an invalid rule, because significance depends on the p-value (F compared with F(3, 32)), and the 5% critical value here is about 2.90.
Q9

Which write-up of the output in Q8 is correct?

  1. Watering: F(1, 32) = 0.01. Interaction: F(1, 32) = 1.242
  2. Sunlight: F(3, 32) = 23.05, p < 0.001. Watering: F(1, 32) = 0.001, p = 0.976. Interaction: F(3, 32) = 1.24, p = 0.311
  3. Sunlight: F(32, 3) = 23.05, p < 0.001
  4. Sunlight: F(3, 32) = 23.05, p = 0.976

Answer: B.

Justification: Each F statistic is reported with the df from its own row (numerator) and the residual df (denominator), exactly as in the output. The note's Format 1 write-up gives the interaction as F(1, 32) and watering as 0.01, which do not match the table. Its claim that heights were "significantly higher when exposed to more sunlight" is also too strong, since the means are not monotone (None 4.07 < Low 5.10 < High 5.55 < Medium 5.89).

Why the others are wrong: A contains the note's two errors. C reverses the numerator and denominator df. D attaches the watering p-value to the sunlight test.
Q10

The note's plotting code:

grp.means <- aggregate(growth ~ watering + sunlight, data = growthData, mean)
> grp.means
  watering sunlight growth
1    Daily     High   5.78
2   Weekly     High   5.32

8   Weekly     None   4.00
> daily.avg;  weekly.avg
[1] 5.78 4.98 5.72 4.14
[1] 5.32 5.22 6.06 4.00

x.labels <- c("None", "Low", "Medium", "High")   # used with plot(1:4, weekly.avg, ...)

The resulting plot suggests the weekly mean is highest at Medium and lowest at High. What is wrong?

  1. type = "b" should be type = "l"
  2. The legend should list "Daily" before "Weekly"
  3. aggregate() computed medians instead of means
  4. The rows of grp.means are in alphabetical order (High, Low, Medium, None), so the labels None and High are attached to the wrong means, and the lowest mean actually belongs to None

Answer: D.

Why the others are wrong: A changes only the line style. B is wrong because the legend order (Weekly, Daily) matches the colors used. C is false, since the function passed was mean.
Q11

The Weekly − Daily mean differences are High −0.46, Low +0.24, Medium +0.34, and None −0.14, so the two lines in the interaction plot cross. The interaction F-test gives p = 0.311. How should this be interpreted?

  1. Non-parallel lines in a sample can arise from random variation. The F-test finds no significant evidence of a true interaction
  2. The lines cross, so the interaction must be significant and the ANOVA is wrong
  3. p = 0.311 proves that the population lines are exactly parallel
  4. A non-significant watering main effect means an interaction cannot exist

Answer: A.

Justification: The note uses a line plot as a visual aid, but the formal test of H₀ (no interaction) is the F-test. Here F(3, 32) = 1.24 and p = 0.311 > 0.05, so the data are consistent with no interaction.

Why the others are wrong: B treats a visual impression as a test result. C treats failure to reject as proof. D is false, because main effects and interaction are separate terms, and crossing patterns can exist even when a main effect is near zero.

Q13

The ANOVA table gave p = 0.976 for watering. Why do these p-values agree?

$watering
               diff        lwr       upr    p adj
Weekly-Daily -0.005 -0.3405535 0.3305535 0.975975
  1. It is a coincidence
  2. With only two levels there is just one comparison, so Tukey's test is equivalent to the F-test (t² = F, same MSE and 32 df), and no multiplicity adjustment is needed
  3. Tukey's method ignores MSE and reuses the ANOVA p-value
  4. Both are small because the watering effect is large

Answer: B.

Justification: With two groups, the F statistic equals the square of the pairwise t statistic. Here t = −0.005/√(0.2714 × 2/20) = −0.030, so t² = 0.0009 = F, and both tests use the same error term. The note describes Tukey as adjusting for multiple comparisons, and one comparison needs no adjustment.

Why the others are wrong: A is wrong because the agreement is mathematical. C is false, since Tukey's intervals are built from MSE. D is false, because p = 0.976 is large and means there is no evidence of a watering effect.

  1. There are only 8 comparisons, so all are meaningful

Part D: Assumptions and broader issues

Q16

The note says homogeneity of variance should be checked for each combination of factor levels.

> bartlett.test(growth ~ interaction(sunlight, watering), data = growthData)

	Bartlett test of homogeneity of variances

data:  growth by interaction(sunlight, watering)
Bartlett's K-squared = 4.0503, df = 7, p-value = 0.774

Which interpretation is correct?

  1. The large p-value means the variances differ across cells
  2. The df should be 1, because there are two watering levels
  3. H₀ (equal variances across the 8 cells) is not rejected, so there is no evidence against homogeneity. The df is 8 − 1 = 7
  4. The test checks normality

Answer: C.

Justification: Bartlett's H₀ is that all group variances are equal, and p = 0.774 is far above 0.05. The test compares 8 cell variances, which gives df = 7. Failing to reject is not proof, but the cell variances (0.085 to 0.447) show no strong sign of heterogeneity.

Why the others are wrong: A reverses the decision rule. B counts only one factor's levels. D is wrong because normality is checked with Shapiro–Wilk or a Q-Q plot.
Q17 
> shapiro.test(residuals(growth.aov))

	Shapiro-Wilk normality test

data:  residuals(growth.aov)
W = 0.95274, p-value = 0.0943

Which statement is correct?

  1. Since W < 1, normality is rejected
  2. H₀ (normality) is not rejected at 0.05, so there is no strong evidence against the normality assumption
  3. The p-value is the probability that the data are normal
  4. The test shows that the cell variances are equal

Answer: B.

Justification: The note requires approximate normality and names Shapiro–Wilk as a check. With p = 0.094 > 0.05, H₀ is not rejected. The p-value is only moderately large, so this check does not clear the data entirely, and a Q-Q plot is a useful companion.

Why the others are wrong: A misreads W, since W is always below 1 for real data and the decision rests on p. C misreads the p-value. D confuses normality with equal variances (Bartlett's or Levene's test).
Q18

A different experiment gives the following output (hypothetical).

            Df Sum Sq Mean Sq F value   Pr(>F)
A            2     30   15.00      12 0.000244 ***
B            1      5    5.00       4 0.056940 .
A:B          2     20   10.00       8 0.002177 **
Residuals   24     30    1.25

What should the analyst do next?

  1. Interpret the main effect of A on its own, since it is highly significant
  2. Ignore the interaction because B is not significant
  3. Drop the interaction and refit without it
  4. Treat the significant interaction (p ≈ 0.002) as meaning the effect of one factor depends on the level of the other, and compare cell means within combinations using Tukey-adjusted comparisons

Answer: D.

Justification: The note says a significant interaction means one factor's impact depends on the other, so groups must be compared within combinations, with simultaneous methods such as Tukey's HSD to control the family-wise error rate.

Why the others are wrong: A uses an averaged main effect that may be misleading when the effect of A varies with B. B is wrong because the interaction has its own test and is significant. C discards a significant term to make the results easier to read.
Q19

An RBD has 3 treatments (a = 3) and 4 blocks (b = 4) with one observation per cell, so N = 12. What does the note imply about the interaction?

  1. DF.E = N − ab = 0, so there are no error df and the interaction cannot be tested
  2. DF.E = 6, so the interaction can be tested with 6 df
  3. DF.E = 11, so the interaction can be tested
  4. DF.E = 12, so the interaction can be tested

Answer: A.

Justification: The note states that the interaction effect is not available for RBD data with no replicates. Using DF.E = N − ab gives 12 − 12 = 0, so there is no pure-error estimate. In practice one fits the additive model aov(y ~ trt + block), whose 6 residual df combine interaction and error.

Why the others are wrong: B describes the additive model's residual df but wrongly treats them as a separate interaction test. C is the total df (N − 1). D is N itself.
Q20

Each plant's height is measured monthly for six months, and the researcher wants to compare sunlight levels. Which analysis is appropriate?

  1. The two-way ANOVA from this note, since the design has two factors
  2. A replicated RBD analysis with more replicates
  3. Repeated-measures ANOVA, because repeated measurements on the same subject are not independent
  4. One-way ANOVA on the pooled measurements

Answer: C.

Justification: The note's caution says the one-way and two-way methods assume independent observations. Measuring the same characteristic on the same subject multiple times requires repeated-measures ANOVA, which differs from the analysis for a replicated RBD.

Why the others are wrong: A, B, and D all treat repeated measurements on one plant as independent observations, which violates the assumption.
