Question 1

The note creates a toy data frame my.toy.data with a variable salary. Which R command correctly extracts the salary variable?

  1. my.toy.data$Salary
  2. my.toy.data$salary
  3. my.toy.data$sAlaRy
  4. my.toy.data@salary

Correct answer: B

Justification: The note explicitly warns that R is case sensitive; my.toy.data$salary is the correct extraction, whereas $Salary or $sAlaRy will produce errors.

Why others are incorrect:

  • A and C use incorrect capitalization; R will not recognise the column.
  • D uses the @ slot operator, which is not used for extracting columns from a data frame.
Question 2

Which statement about the assumptions of the one-sample t-test is true according to the note?

  1. The sample size must be at least 30.
  2. The population must be normally distributed, and observations must be independent.
  3. The population standard deviation must be known.
  4. The data must be ordinal.

Correct answer: B

Justification: The note states that the basic assumptions are that the population is normal \(N(\mu,\sigma)\) and that the data are independently taken from that population. It also explicitly notes that “small sample size is not an assumption for t-test”.

Why others are incorrect:

  • A is false; small samples are allowed if normality holds.
  • C is false; the t-test is used when \(\sigma\) is unknown.
  • D is false; the t-test is for continuous numerical data, not ordinal data.
Question 3

The note performs a manual one-sample t-test on BMI with \(H_0:\mu=30\) and obtains the following R output:

      xbar       TS d.f.      p.value
[1,] 33.08622 8.694805  391 9.708976e-17

At \(\alpha=0.05\), what is the correct conclusion?

  1. Fail to reject \(H_0\); the mean BMI is 30.
  2. Reject \(H_0\); the mean BMI is not 30.
  3. Accept \(H_0\); there is no evidence of a difference.
  4. The test is invalid because the p-value is too small.

Correct answer: B

Justification: The p-value is essentially 0, so \(H_0:\mu=30\) is rejected. The note states, “The p-value is close to 0, the null hypothesis \(H_0:\mu=30\) is rejected!”

Why others are incorrect:

  • A and C would be correct only if the p-value were large.
  • D is nonsensical; a very small p-value is evidence against \(H_0\), not a sign of invalidity.
Question 4

The built-in t.test for BMI gives:

t = 8.6948, df = 391, p-value < 2.2e-16
95 percent confidence interval:
 32.38837 33.78407
sample estimates:
mean of x
 33.08622

Which interpretation of the 95% confidence interval is correct?

  1. There is a 95% probability that the sample mean lies between 32.388 and 33.784.
  2. We are 95% confident that the true population mean BMI lies between 32.388 and 33.784.
  3. 95% of the BMI observations lie between 32.388 and 33.784.
  4. The interval contains 30, so \(H_0:\mu=30\) cannot be rejected.

Correct answer: B

Justification: The output is a confidence interval for the population mean. The note presents this interval as part of the t.test output for \(\mu\).

Why others are incorrect:

  • C describes a prediction interval, not a confidence interval for the mean.
  • D is false; the interval does not contain 30, consistent with rejecting \(H_0\).
Question 5

In the regression approach to the one-sample t-test, the note uses:

lm(I(BMI - 30) ~ 1, data = PimaIndiaDiabetes)

What is the purpose of subtracting 30 inside I()?

  1. To standardise the BMI values.
  2. To test \(H_0:\mu=30\) by testing whether the intercept of the shifted response is 0.
  3. To remove outliers from the data.
  4. To convert BMI into a categorical variable.

Correct answer: B

Justification: The note explains that testing \(H_0:\mu=\mu_0\) is equivalent to testing \(H_0:\beta_0-\mu_0=0\) in the model \(y-\mu_0=(\beta_0-\mu_0)+\epsilon\). The I() function allows the expression \(y-\mu_0\) to be used in the model formula.

Why others are incorrect:

  • A is not the goal; standardisation would divide by the standard deviation.
  • C is unrelated; shifting does not remove outliers.
  • D is false; BMI remains numeric.
Question 6

The regression output is:

Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept)  3.086     0.355    8.695   <2e-16

What does the intercept estimate 3.086 represent?

  1. The sample mean BMI.
  2. The difference between the sample mean BMI and the hypothesised mean 30.
  3. The standard deviation of BMI.
  4. The p-value of the test.

Correct answer: B

Justification: The note interprets the intercept as \(\bar{y}-\mu_0\). Here \(\bar{y}=33.086\), so \(33.086-30=3.086\).

Why others are incorrect:

  • A is the sample mean, 33.086, not 3.086.
  • C is the residual standard error, not the intercept.
  • D is a probability, not an estimate of a mean difference.
Question 7

Which statement best describes the relationship between the one-sample t-test and the regression model \(y=\beta_0+\epsilon\)?

  1. The t-test tests \(\beta_1=0\), while regression tests \(\beta_0=0\).
  2. The one-sample t-test is a special case of regression with no predictor, testing whether the intercept equals a hypothesised value.
  3. Regression requires a predictor, so the two methods are unrelated.
  4. The t-test is only valid when the regression slope is zero.

Correct answer: B

Justification: The note states that for a one-sample t-test there is no independent variable \(x\), and fitting \(y=\beta_0+\epsilon\) is equivalent to estimating \(\beta_0\) as the mean of \(Y\). Testing \(H_0:\mu=\mu_0\) is equivalent to testing \(H_0:\beta_0=\mu_0\) in the intercept-only model.

Why others are incorrect:

  • A confuses intercept and slope.
  • C is false; an intercept-only regression is still a regression model.
  • D is irrelevant; there is no slope in a one-sample setting.
Question 8

In the sign test, under \(H_0\), the test statistic \(S\) (number of positive signs) follows which distribution?

  1. Normal distribution with mean 0 and variance 1.
  2. \(t\)-distribution with \(n-1\) degrees of freedom.
  3. Binomial distribution with \(n\) trials and success probability 0.5.
  4. Chi-square distribution with \(n-1\) degrees of freedom.

Correct answer: C

Justification: The note states that under \(H_0\), the sign-test statistic follows a binomial distribution: \(S \sim \text{Binom}(n, p=0.5)\).

Why others are incorrect:

  • A is the large-sample approximation, not the exact null distribution.
  • B is the null distribution for the t-test, not the sign test.
  • D is unrelated to the sign test.
