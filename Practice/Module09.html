Question 1

In the note, what does a randomized block design (RBD) add compared with a completely randomized design (CRD)?

  1. It removes the need for an ANOVA table.
  2. It adds one additional factor variable, so both the additional factor and the treatment effect can be assessed.
  3. It replaces the response variable with a block variable.
  4. It guarantees that no interaction effect can exist.

Correct answer: B

Justification: The note states that RBD designs add one additional factor variable and that researchers are interested in assessing the effects of both the additional factor and the treatment effect.

Why the other choices are incorrect:

  • A: ANOVA is still used; the RBD simply changes the sum-of-squares decomposition.
  • C: The response variable remains continuous; the block factor is added.
  • D: If the RBD has replicates, an interaction effect can be assessed; it is not automatically absent.
Question 2

Which null hypothesis corresponds to the interaction effect in a two-way ANOVA?

  1. All levels of Factor A have the same mean effect.
  2. All levels of Factor B have the same mean effect.
  3. There is no interaction between Factor A and Factor B.
  4. All group variances are equal.

Correct answer: C

Justification: The note defines the interaction hypotheses as H0: There is no interaction between Factor A and Factor B, versus Ha: There is a significant interaction effect.

Why the other choices are incorrect:

  • A: This is the null hypothesis for the main effect of Factor A.
  • B: This is the null hypothesis for the main effect of Factor B.
  • D: Equal variances are an assumption, not an ANOVA null hypothesis about means or interaction.
Question 3

If Factor A has a = 4 levels and Factor B has b = 2 levels, what are the numerator degrees of freedom for the interaction F-test?

  1. 3
  2. 8
  3. 5
  4. 1

Correct answer: A

Justification: The interaction test statistic is

FAB = MSAB / MSE ~ F(a−1)(b−1), N−ab.

Thus, (a − 1)(b − 1) = (4 − 1)(2 − 1) = 3. The note gives this F-distribution for the interaction effect.

Why the other choices are incorrect:

  • B: 8 = ab, which is the number of treatment combinations, not interaction df.
  • C: 5 = a + b − 1, not the interaction df.
  • D: 1 = b − 1, which is the df for Factor B, not the interaction.
Question 4

For a two-way ANOVA with N = 40, a = 4, and b = 2, what is the residual degrees of freedom DF.E?

  1. 32
  2. 39
  3. 33
  4. 36

Correct answer: A

Justification: The note gives

DF.E = N − ab.

Therefore, DF.E = 40 − (4)(2) = 40 − 8 = 32. This matches the residual df in the plant-growth output.

Why the other choices are incorrect:

  • B: 39 = N − 1, the total df.
  • C: 33 comes from an incorrect subtraction.
  • D: 36 does not correspond to any standard df in this design.

# sunlight:watering 3 1.011 0.337 1.242 0.311

At the 5% significance level, which effect is statistically significant?

  1. Sunlight only
  2. Watering only
  3. The interaction only
  4. All three effects

Correct answer: A

Justification: The p-value for sunlight is 3.9 × 10−8 < 0.05, so the sunlight main effect is significant. The watering p-value is 0.976, and the interaction p-value is 0.311, both greater than 0.05.

Why the other choices are incorrect:

  • B: Watering has p = 0.976, so it is not significant.
  • C: The interaction has p = 0.311, so it is not significant.
  • D: Only sunlight is significant.

Correct answer: B

Question 8

Question 9

To compute the p-value for the sunlight F-statistic 23.049 with df1 = 3 and df2 = 32, which R command is correct?

  1. pf(23.049, 3, 32, lower.tail = TRUE)
  2. pf(23.049, 32, 3, lower.tail = FALSE)
  3. pf(23.049, 3, 32, lower.tail = FALSE)
  4. pf(23.049, 3, 32)

Correct answer: C

Justification: The note recommends using

pf(F, df1, df2, lower.tail = FALSE)

to obtain the upper-tail p-value for an ANOVA F-test.

Why the other choices are incorrect:

  • A: lower.tail = TRUE gives the lower-tail probability, not the ANOVA p-value.
  • B: The degrees of freedom are reversed.
  • D: The default is lower.tail = TRUE, so this also gives the wrong tail probability.

Question 19

If a two-way ANOVA reveals a significant interaction effect, what does the note recommend for post-hoc comparisons?

  1. Compare only the overall main-effect means and ignore combinations.
  2. Compare groups within factor-level combinations and use a simultaneous method such as Tukey’s HSD to control the family-wise error rate.
  3. Do not perform any post-hoc comparisons.

Correct answer: B

Justification: The note states that when interaction is significant, the impact of one factor depends on the level of the other, so groups within combinations should be compared, and simultaneous methods such as Tukey’s HSD should be used to control inflated Type I error rates.

Why the other choices are incorrect:

  • C: Post-hoc comparisons are especially important after a significant interaction.
  • D: A one-way ANOVA would ignore the two-factor structure and interaction.
