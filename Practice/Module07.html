Part 1. Introduction & Accessing Data in R

Question 1

According to the note, which statement correctly distinguishes parametric from nonparametric two-sample tests?

  1. Parametric tests make fewer assumptions about the data distribution
  2. Parametric tests assume data follows a specific distribution (usually normal) and compare parameters like means or variances; nonparametric tests make fewer distributional assumptions and are used when parametric assumptions are violated
  3. Nonparametric tests can only be used for paired samples
  4. Parametric tests require the population variances to be known

Answer: B

Justification: The note’s introduction classifies two-sample tests into parametric tests, which “assume data follows a specific distribution (usually normal) and compare parameters like means or variances,” and nonparametric tests, which “make fewer assumptions about the data distribution and are used when parametric assumptions are violated.”

Why the other options are incorrect:

  • A reverses the definitions — it is the nonparametric tests that make fewer assumptions.
  • C is false — the note uses nonparametric tests (Wilcoxon rank sum) for independent samples as well as paired ones.
  • D is false — the two-sample t-test explicitly assumes the population variances are unknown (they are estimated by pooling).
Question 2

  4. female.salary will contain 0 rows because no condition was given for females

Answer: B

Justification: The note’s comments state that which(my.toy.data$gender == "M") “will return the row indexes of male employees,” and that -male.id means “not male ⇒ female indexes.” The == is a logical test, which() converts the TRUE/FALSE vector into positions, and negative indexing drops those positions.

  • D is wrong because -male.id selects all rows except the male ones, i.e., exactly the 4 female rows.

Part 2. The Two-Sample t-Test

Question 5

What are the two assumptions of the two-sample (pooled) t-test recalled from introductory statistics?

  1. Both populations are normally distributed; both population variances are unknown but equal
  2. Both samples have the same size; both populations have the same mean
  3. The data are paired; the differences are normally distributed
  4. Both populations are normally distributed; the variances are known constants

Answer: A

Justification: The note states the assumptions directly: “Both populations are normally distributed” and “Both population variances are unknown but equal.” The equal-variance assumption is what justifies pooling the two samples into a single estimate spool.

Why the other options are incorrect:

  • B — equal sample sizes are not required, and equal means is the null hypothesis being tested, not an assumption.
  • C describes the paired t-test setting (assumptions on the differences), a different design covered later in the note.
  • D — the variances are assumed unknown; known variances would call for a z-test.
Question 6

Two independent samples have n₁ = 10, s₁ = 6 and n₂ = 15, s₂ = 4. Using the pooling formula below, the pooled standard deviation equals approximately:

spool = √[ ((n₁ − 1)s₁² + (n₂ − 1)s₂²) / (n₁ + n₂ − 2) ]

  1. 5.10
  2. 4.88
  3. 5.00
  4. 4.68

Answer: B

Justification: spool² = (9·36 + 14·16)/23 = (324 + 224)/23 = 548/23 ≈ 23.83, so spool ≈ √23.83 ≈ 4.88. The weights are the degrees of freedom (ni − 1), and the divisor is the pooled degrees of freedom n₁ + n₂ − 2.

Why the other options are incorrect:

  • A (5.10) comes from the unweighted root-mean-square √((36 + 16)/2) = √26 — it ignores the degrees-of-freedom weights.
  • C (5.00) is the simple arithmetic mean (6 + 4)/2 — standard deviations are not averaged directly.
  • D (4.68) results from dividing by n₁ + n₂ = 25 instead of n₁ + n₂ − 2 = 23 — the wrong denominator.
Question 7

Under the two-sample t-test assumptions, the test statistic below follows which distribution, and with what degrees of freedom (as applied to the Pima diabetes data, where the output reports df = 390)?

TS = (x̄₁ − x̄₂) / ( spool · √(1/n₁ + 1/n₂) )

  1. Standard normal N(0,1), with df = n₁ + n₂
  2. t-distribution with n₁ + n₂ − 2 degrees of freedom (so n₁ + n₂ = 392 for the Pima data)
  3. t-distribution with n₁ + n₂ − 1 degrees of freedom
  4. F-distribution with 1 and n₁ + n₂ − 2 degrees of freedom

Answer: B

Justification: The note gives the sampling distribution as TS ~ tn₁+n₂−2, and the Pima output confirms “df = 390,” i.e., n₁ + n₂ − 2 = 390, so the two samples total 392 observations. Estimating the two sample means costs one degree of freedom each, so two are lost from n₁ + n₂.

Why the other options are incorrect:

  • A — the standard normal applies only with known σ; here σ is estimated by spool, giving a t-distribution.
  • C subtracts only one degree of freedom — there are two sample means being estimated.
  • D — the F distribution arises in the regression/ANOVA formulation (e.g., F = 30.7 in the lm output); the two-sample t statistic itself is t-distributed (though t² = F with 1 numerator df).
Question 8

The manual R calculation for the Pima data ends with the code and output below. Why is the p-value computed as 2*pt(abs.TS, ..., lower.tail = FALSE)?

p.value <- 2*pt(abs.TS, df = n1+n2-2, lower.tail = FALSE)
cbind(TS = TS, df = n1 +n2 - 2, p.value = p.value)

            TS  df      p.value
[1,]  5.540362 390 5.563221e-08
  1. lower.tail = FALSE gives the right-tail probability; doubling it accounts for the two-sided alternative Ha: μ₁ − μ₂ ≠ 0
  2. The factor 2 corrects for the two samples, and lower.tail = FALSE selects the left tail
  3. pt() always returns negative values, so the absolute value and factor 2 are needed to make it positive
  4. Doubling converts the t-distribution to the F-distribution

Answer: A

Justification: The code comment says “p-value: 2 times the right-tail area for a two-sample test,” and lower.tail = FALSE specifies the right tail. Because the alternative is two-sided (Ha: μ₁ − μ₂ ≠ 0), evidence against H₀ in either direction counts, so the one-tail area is doubled. With p = 5.56×10⁻⁸ < 0.05, the note concludes there is strong evidence the mean BMIs differ.

Why the other options are incorrect:

  • B — lower.tail = FALSE is the right tail, not the left.
  • C — pt() returns valid probabilities in [0, 1]; abs() is used because the two-sided p-value depends only on |TS|.
  • D — nothing here converts distributions; squaring (not doubling) relates t to F.
Question 9

The built-in test produces the output below. Which statement is correct?

t.test(diabetes.pop$mass, no.diabetes.pop$mass, alternative = "two.sided", var.equal = TRUE)

 2.597924 5.455934

  1. The argument var.equal = TRUE requests Welch’s approximate (unequal-variance) procedure
  2. The confidence interval (2.598, 5.456) is for the diabetes group mean alone; its midpoint 4.027 confirms normality
  3. Setting var.equal = TRUE invokes the pooled two-sample t-test, and the interval’s midpoint (2.597924 + 5.455934)/2 = 4.0269 equals x̄₁ − x̄₂ = 35.77769 − 31.75076 — matching the manual calculation exactly
  4. The p-value 5.563e-08 exceeds 0.05, so the mean BMIs are not significantly different

Justification: The note states the built-in function “produces the same results” as the manual calculation (TS = 5.5404, df = 390, p = 5.563e-08).   • B misidentifies the estimand — the interval estimates the difference of means, and an interval midpoint says nothing about normality.
  • D misreads the conclusion — 5.563×10⁻⁸ is far below 0.05, so H₀ is rejected; the note calls this “clear strong evidence” of a difference.

Coefficients:

F-statistic: 30.7 on 1 and 390 DF,  p-value: 5.563e-08
  1. Intercept 31.7508 = x̄₂ (the baseline, diabetes-free mean)
  2. factor(diabetes)pos estimate 4.0269 = x̄₁ − x̄₂ = 35.77769 − 31.75076
  3. Residual standard error 6.775 on 390 df = the pooled standard deviation spool with df = n₁ + n₂ − 2

Part 4. Wilcoxon Rank Sum (Mann–Whitney U) Test

Question 11

Which statement about the Wilcoxon Rank Sum Test is consistent with the note?

  1. It tests whether the two population medians are equal, regardless of distribution shape
  2. It assesses whether the two population distributions are equal; interpreting it as a median test is valid only if the distributions are symmetric and differ only in location
  3. It assumes both populations are normal with equal variances
  4. It requires the data to be paired

Answer: B

Justification: The note states the test “assesses whether the two population distributions are equal” and warns that the common misconception that it compares medians “is only true if the distributions are symmetric and differ only in location.” The accompanying figure shows two distributions with the same mean but different shapes — the test can reject H₀ even when location parameters coincide.

Why the other options are incorrect:

  • A is precisely the “common misconception” the note debunks — different shapes (skewness, variance) can drive rejection even with equal medians.
  • C describes the parametric t-test assumptions; the rank sum test is introduced precisely for cases where normality/equal-variance assumptions are violated.
  • D describes the paired design; the rank sum test is for two independent samples.
Question 12

Group A = (10, 12, 14, 16), Group B = (15, 18, 20, 22). After combining and sorting (10, 12, 14, 15, 16, 18, 20, 22) and assigning ranks 1–8, what are the rank sums?

  1. RA = 10, RB = 26
  2. RA = 11, RB = 25
  3. RA = 14, RB = 22
  4. RA = 12, RB = 24

Answer: B

Justification: Group A’s values receive ranks 1 (for 10), 2 (for 12), 3 (for 14), and 5 (for 16, since 15 takes rank 4): RA = 1+2+3+5 = 11. Group B receives ranks 4, 6, 7, 8: RB = 25. Sanity check: RA + RB = 36 = 8(8+1)/2, the sum of ranks 1 through 8.

Why the other options are incorrect:

  • A would require Group A to hold ranks 1, 2, 3, 4 (the four smallest values), but rank 4 belongs to Group B’s value 15.
  • C does not match the ranks actually assigned — Group A’s ranks are 1, 2, 3, 5, which sum to 11, not 14.
  • D also fails the check — Group A’s ranks sum to 11; no assignment of A’s values yields 12.
Question 13

Using RA = 11, RB = 25, and n₁ = n₂ = 4, compute the U statistics:

  1. U₁ = 1, U₂ = 15, U = 1
  2. U₁ = 15, U₂ = 1, U = 1
  3. U₁ = 15, U₂ = 1, U = 15
  4. U₁ = 11, U₂ = 25, U = 11

Answer: B

Justification: U₁ = 4·4 + 4·5/2 − 11 = 16 + 10 − 11 = 15; U₂ = 16 + 10 − 25 = 1; U = min{15, 1} = 1, matching the note’s worked example (and R’s output W = 1).

Why the other options are incorrect:

  • A swaps which U belongs to which group — group 1 (A) has the smaller rank sum (11), and a smaller rank sum gives a larger U, so U₁ must be 15.
  • C correctly computes U₁ and U₂ but takes the maximum instead of the minimum — the note defines U = min{U₁, U₂}.
  • D merely repeats the rank sums rather than applying the U formulas. (Consistency check: U₁ + U₂ = 16 = n₁n₂ ✓.)
Question 14

For n₁ = n₂ = 4 at α = 0.05 (one-tailed), the note’s U-table gives critical value CV = 0, with the decision rule: reject H₀ if U < CV or U > n₁n₂ − CV; fail to reject H₀ if CV < U < n₁n₂ − CV. With U = 1, the conclusion is:

  1. Reject H₀, because U = 1 is smaller than n₁n₂ = 16
  2. Fail to reject H₀, because 0 = CV < U = 1 < 16 = n₁n₂ − CV; the distributions are not significantly different
  3. Reject H₀, because U is below the mean μU = n₁n₂/2 = 8
  4. The test cannot be performed, because exact tables require n₁, n₂ > 20

Answer: B

Justification: The note applies the rule directly: “0 = CV0.05 < U < 16, we fail to reject the null hypothesis H₀. That is, the two distributions are not significantly different.” This matches the R result (p-value = 0.05714 > 0.05).

Why the other options are incorrect:

  • A misapplies the rule — rejection requires U outside the interval (CV, n₁n₂ − CV); being small relative to 16 is not the criterion.
  • C — lying below μU shows a direction of difference but does not define the rejection region; the critical-value boundaries do.
  • D reverses the conditions — exact tables are for small samples (n₁, n₂ ≤ 20); the normal approximation is used when both exceed 20.

  3. exact = FALSE forces the t-distribution, giving a more conservative test
  4. The sample is too small for any test, so the p-value is unreliable and H₀ is retained

Answer: A

Justification: The note says: “Since both sample sizes are larger than 20, we will use the approximation approach for the p-value,” consistent with the normal approximation being valid when n₁ > 20 and n₂ > 20. Part 5. Paired-Sample Tests

Question 16

A clinical trial measures systolic blood pressure in the same 10 patients before and after 4 weeks of medication. Why are the independent two-sample tests of the earlier sections inappropriate, and what is the remedy?

  1. They are inappropriate because the sample size is too small; the remedy is to collect more patients
  2. Each pair of measurements comes from the same patient and is therefore correlated (dependent); taking the within-patient difference converts the two-correlated-sample problem into a one-sample problem
  3. They are inappropriate because blood pressure is not normally distributed; the remedy is a log transformation
  4. They are inappropriate because the two time points have different variances; the remedy is Welch’s test

Answer: B

Justification: The note explains that because each pair of measurements is taken from the same patient and is therefore correlated (dependent), the two-sample tests of previous sections cannot be used. Taking the difference between each pair gives each subject a single value, which “transforms the two-correlated-sample problem into a one-sample situation.”

Why the other options are incorrect:

  • A — small size affects power and normality checks, but the fundamental problem is the dependence between paired measurements, which violates the independent-samples design regardless of n.
  • C — normality of BP is not the stated obstacle; the paired design is the issue, and no transformation is proposed.
  • D — unequal variances are not the reason; the dependence structure is, and the remedy is differencing, not Welch’s procedure.

Question 18

The assumptions of the paired-sample t-test, as stated in the note, are:

  2. The differences are normally distributed; the standard deviation of the population of differences is unknown

Question 19

In the pain-relief example, differences (after − before) are computed and Patient 2’s difference of 0 is removed, leaving n = 9. The absolute differences are ranked with ties handled as follows: five 1s share average rank (1+2+3+4+5)/5 = 3, and the two 2s share (6+7)/2 = 6.5. The sum of ranks for the positive differences (+1, +1) is 3 + 3 = 6, and the test statistic is the smaller rank sum, W = 6. From the Wilcoxon critical value table at α = 0.05 for n = 9, the critical value is 5. Which statement is accurate?

  1. W = 6 is the sum of the signed ranks, including zeros
  2. Zero differences must be excluded before ranking; tied absolute values receive their average rank; with R’s wilcox.test(paired = TRUE) returning V = 39 and p = 0.04639 < 0.05, H₀ (median difference = 0) is rejected
  3. Because the five 1s all received rank 3, the ranking is invalid — each observation needs a distinct rank
  4. W = 6 exceeds the critical value 5, so by the table the treatment is ineffective

Answer: B

Justification: The note’s steps are: (1) exclude zero differences (Patient 2 is removed, leaving n = 9); (2) rank the absolute differences, with tied values receiving the average rank (five 1s → 3; two 2s → 6.5); (3) the test statistic W is the smaller rank sum, 6. The R output of wilcox.test(before, after, paired = TRUE, exact = FALSE, correct = FALSE) gives V = 39, p = 0.04639, and the note concludes that p < 0.05, so the null hypothesis is rejected. The hypotheses concern the median difference (the signed-rank test “assesses whether the median difference between pairs is zero”).

Side note: W = 6 is only one unit above the table value of 5, so this case is borderline — the exact-table comparison and the normal-approximation p-value (0.046) sit close to the 0.05 boundary. The decision in this note follows the R p-value.

Why the other options are incorrect:

  • A — zeros are excluded, not included, and ranks are assigned to absolute differences (signs are used only to split the rank sums afterwards).
  • C — average ranks for ties are the note’s explicit convention (also used in the rank-sum procedure).
  • D bases the decision on a bare comparison of W with a table value and declares the treatment “ineffective”; the note’s conclusion follows the R p-value (0.04639 < 0.05), which rejects H₀.
Question 20

Which statement correctly contrasts the two nonparametric tests in this note?

  1. wilcox.test(x, y, paired = FALSE) performs the signed-rank test on independent samples
  2. The Wilcoxon rank sum test is for two independent samples and tests equality of distributions; the Wilcoxon signed-rank test is for paired samples and tests whether the median difference is zero — the latter being the nonparametric alternative to the paired t-test
  3. The signed-rank test requires normality of the differences, while the rank sum test does not
  4. Both tests require the populations to be normally distributed with equal variances

Answer: B

Justification: The note introduces the rank sum test (Mann–Whitney U) for independent samples with H₀: “the two population distributions are equal,” implemented with paired = FALSE (the default). It introduces the signed-rank test as “a nonparametric alternative to the paired t-test, used when comparing two related (paired) samples where data is not normally distributed,” which assesses whether the median difference between pairs is zero, implemented with paired = TRUE.

Why the other options are incorrect:

  • A reverses the argument mapping — paired = FALSE gives the independent-samples rank sum test.
  • C reverses the assumption logic — the signed-rank test is used precisely when the differences are not normal; normality of differences is the paired t-test’s assumption.
  • D describes the parametric t-test assumptions; both Wilcoxon procedures were introduced for situations where those assumptions fail.
