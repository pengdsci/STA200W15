Question 2

When the population is normally distributed and the population standard deviation (\(\sigma\)) is known, the standardized statistic \(\dfrac{\bar{x} - \mu}{\sigma/\sqrt{n}}\) follows which distribution?

  1. \(t\)-distribution with \(n - 1\) degrees of freedom
  2. Standard normal distribution (\(Z\))
  3. Chi-square distribution
  4. \(F\)-distribution

Correct Answer: B. Standard normal distribution (\(Z\))

Justification: In Scenario #2 of the note, with a normal population and known \(\sigma\), the standardized score is \(\dfrac{\bar{x} - \mu}{\sigma/\sqrt{n}} \rightarrow N(0,1)\).

Why other choices are incorrect:

  • A is used only when \(\sigma\) is unknown and the population is normal (Scenario #3).
  • C and D are not appropriate for a single mean with known \(\sigma\).
Question 3

A sample of size \(n = 100\) yields \(\bar{x} = 7.5\) and \(s = 2.3\). For a 95% confidence interval for \(\mu\), what is the margin of error?

  1. 0.045
  2. 0.45
  3. 0.23
  4. 0.023

Correct Answer: B. 0.45

Justification: The margin of error is

\[ E = 1.96 \times \frac{2.3}{\sqrt{100}} = 1.96 \times 0.23 \approx 0.4508 \approx 0.45. \]

Why other choices are incorrect:

  • A (0.045) is off by a factor of 10.
  • C (0.23) is the standard error itself, not the margin of error.
  • D (0.023) is off by a factor of 20 (it is the standard error divided by 10).

R illustration:

x <- c(7.5)   # placeholder; with raw data use:
# t.test(x, conf.level = 0.95)
1.96 * 2.3 / sqrt(100)
#> [1] 0.4508
Question 4

In the note’s Example 2 (survey of 1219 U.S. adults, 354 prefer football), the 95% confidence interval for the population proportion is approximately:

  1. (0.264, 0.316)
  2. (0.265, 0.315)
  3. (0.2645, 0.3155)
  4. (0.26, 0.32)

Correct Answer: C. (0.2645, 0.3155)

Justification: The note calculates \(\hat{p} = 354/1219 \approx 0.29\),

\[ E = 1.96 \times \sqrt{\frac{0.29(1 - 0.29)}{1219}} \approx 0.0255, \]

giving the interval \((0.2645,\;0.3155)\).

Why other choices are incorrect:

  • A and B round the interval to three decimals but miss the exact values shown in the note.
  • D is a rounded version but not the precise interval given in the note.

R illustration:

prop.test(354, 1219, conf.level = 0.95)$conf.int
#> [1] 0.2653 0.3153

Question 11

A one-sample \(t\)-test in R returns \(t = 2.45\), df = 9, \(p\)-value = 0.037. At \(\alpha = 0.05\), what is the correct decision?

  1. Fail to reject \(H_0\) because \(p > 0.05\).
  2. Reject \(H_0\) because \(p < 0.05\).
  3. Accept \(H_0\) because the \(t\)-value is positive.
  4. The result is inconclusive.

Correct Answer: B. Reject \(H_0\) because \(p < 0.05\)

Justification: The decision rule is to reject \(H_0\) when the \(p\)-value \(\le \alpha\). Here \(0.037 \le 0.05\), so we reject \(H_0\).

Why other choices are incorrect:

  • A contradicts the \(p\)-value rule.
  • C is incorrect; the sign of the \(t\)-statistic does not determine the decision.
  • D is not true; the \(p\)-value provides a clear decision.
Question 12

  1. We fail to reject \(H_0\) when \(H_0\) is false.
  2. We reject \(H_0\) when \(H_0\) is true.
  3. We reject \(H_0\) when \(H_0\) is false.
  4. We fail to reject \(H_0\) when \(H_0\) is true.

Correct Answer: B. We reject \(H_0\) when \(H_0\) is true

Justification: A Type I error is the rejection of a true null hypothesis. The note discusses the decision process but does not explicitly define Type I/II errors; however, this is a standard concept in hypothesis testing.

  • C is a correct decision.
  • D is a correct decision.

Question 19

In the note’s Example 1 (walleye fingerlings), the 95% confidence interval for the mean length is (7.05, 7.95). Which statement is correct?
