Question 1

What is the structural form of the simple linear regression model as described in the note?

  1. \(Y = \beta_0 + \beta_1X\)
  2. \(Y = \beta_0 + \beta_1X + \epsilon\)
  3. \(Y = b_0 + b_1X + e\)
  4. \(\hat{Y} = \beta_0 + \beta_1X\)

Correct Answer: B. \(Y = \beta_0 + \beta_1X + \epsilon\)

Justification: The note explicitly states the simple linear regression model is represented as \(Y = \beta_0 + \beta_1X + \epsilon\), where \(\epsilon\) is the random error term assumed to follow \(N(0, \sigma^2)\).

Why other choices are incorrect:

  • A omits the random error term \(\epsilon\), which is essential to the statistical model.
  • C uses estimated coefficients (\(b_0, b_1\)) and residual \(e\), which describe the fitted model, not the population model.
  • D represents the estimated regression line (fitted model), not the theoretical model with random error.
Question 2

In the simple linear regression model, what does the slope parameter \(\beta_1\) represent?

  1. The predicted value of \(Y\) when \(X = 0\)
  2. The change in \(Y\) for a one-unit increase in \(X\)
  3. The correlation between \(X\) and \(Y\)
  4. The residual standard error

Correct Answer: B

Justification: The note defines \(\beta_1\) as “the slope (the change in \(Y\) per unit change in \(X\))”. The summary section reiterates: “Slope (\(\beta_1\)): Change in \(Y\) per unit increase in \(X\)”.

Why other choices are incorrect:

  • A describes the intercept \(\beta_0\), not the slope.
  • C is the Pearson correlation coefficient \(r\), not \(\beta_1\).
  • D is a measure of model fit (residual standard error), not the slope.
Question 3

Which assumption of simple linear regression states that the variance of the errors is constant across all values of \(X\)?

  1. Linearity
  2. Independence
  3. Homoscedasticity
  4. Normality

Correct Answer: C. Homoscedasticity

Justification: The note lists the assumptions and states: “Homoscedasticity: Constant variance of errors across \(X\)”. It further clarifies that the variance of \(Y\) is the same as the residual \(\epsilon\).

Why other choices are incorrect:

  • A (Linearity) assumes the relationship between \(X\) and \(Y\) is linear.
  • B (Independence) assumes errors are uncorrelated.
  • D (Normality) assumes errors are normally distributed.

Question 5

In the note’s example (course grade vs. study hours), what are the degrees of freedom for the \(t\)-test on the slope?

  1. \(n - 1 = 9\)
  2. \(n - 2 = 8\)
  3. \(n = 10\)
  4. \(n + 1 = 11\)

Correct Answer: B. \(n - 2 = 8\)

Justification: The note states: “The degrees of freedom of the t-test in linear regression is defined to be: df = n - # coefficients!” and for the example with \(n = 10\) and two coefficients (intercept and slope), \(df = 10 - 2 = 8\).

Why other choices are incorrect:

  • A would be correct only if there were one coefficient (e.g., a one-sample \(t\)-test).
  • C is the sample size, not the degrees of freedom.
  • D is not a valid formula for regression \(t\)-tests.
Question 6

Refer to the R output for the course grade vs. study hours example. The slope estimate is 2.4364 with standard error 0.1007. What is the value of the \(t\)-statistic for testing \(H_0: \beta_1 = 0\)?

  1. 2.4364
  2. 0.1007
  3. 24.02
  4. 0.0413

Correct Answer: C. 24.02

Justification: The note computes the test statistic as

\[ TS = \frac{b_1 - 0}{SE(b_1)} = \frac{2.4364}{0.1007} \approx 24.02. \]

Why other choices are incorrect:

  • A is the slope estimate itself, not the test statistic.
  • B is the standard error.
  • D is the reciprocal of the test statistic.

R illustration:

2.4364 / 0.1007
#> [1] 24.19464   # approximately 24.02 in the note's rounded display
Question 7

For the course grade example, the \(p\)-value for the slope is \(9.07 \times 10^{-9}\). At \(\alpha = 0.05\), what is the correct conclusion?

  1. Fail to reject \(H_0\); study hours do not significantly affect grade.
  2. Reject \(H_0\); study hours significantly affect grade.
  3. Accept \(H_0\); the slope is zero.
  4. The result is inconclusive because the \(p\)-value is too small.

Correct Answer: B. Reject \(H_0\); study hours significantly affect grade.

Justification: The decision rule is to reject \(H_0\) when the \(p\)-value is less than or equal to \(\alpha\). Since \(9.07 \times 10^{-9} < 0.05\), we reject \(H_0: \beta_1 = 0\). The note’s intended conclusion is that study hours influence the course grade significantly. (The note contains a wording slip when it says “fail to reject” next to a tiny \(p\)-value; the numerical evidence clearly supports rejection.)

Why other choices are incorrect:

  • A contradicts the \(p\)-value rule.
  • C is incorrect because the evidence strongly supports a non-zero slope.
  • D is not true; a small \(p\)-value provides clear evidence against \(H_0\).

Question 10

What is the 95% confidence interval for the slope in the course grade example, given \(b_1 = 2.4364\), \(SE(b_1) = 0.1007\), and \(t_{0.975,8} = 2.306\)?

  1. \((2.2042,\; 2.6686)\)
  2. \((2.4364,\; 2.6686)\)
  3. \((2.2042,\; 2.4364)\)
  4. \((2.3364,\; 2.5364)\)

Correct Answer: A. \((2.2042,\; 2.6686)\)

Justification: The note computes the interval as

\[ b_1 \pm t_{df,1-\alpha/2} \times SE(b_1) = 2.4364 \pm 2.306 \times 0.1007 = (2.204186,\; 2.668614). \]

Why other choices are incorrect:

  • B uses only the upper bound with the point estimate.
  • C uses only the lower bound with the point estimate.
  • D is not the correct calculation.

R illustration:

2.4364 + c(-1, 1) * qt(0.975, 8) * 0.1007
#> [1] 2.204186 2.668614

Question 14

In the context of regression diagnostics, what is leverage?

  1. An observation with an unusual \(Y\) value.
  2. A measure of how far an independent variable value deviates from its mean.
  3. An observation that significantly changes the regression coefficients when removed.
  4. The ratio of residual variance to total variance.

Correct Answer: B. A measure of how far an independent variable value deviates from its mean.

Justification: The note defines leverage as a measure of how far an independent variable (\(X\)) value deviates from its mean. High leverage points have unusual \(X\) values and can potentially influence the fitted regression line.

Why other choices are incorrect:

  • A describes an outlier (an unusual \(Y\) value), not leverage.
  • C describes an influential point, which is related to but not the same as leverage.
  • D is not the definition of leverage.
