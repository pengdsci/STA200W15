Part 1: Foundations (model types, linearity, polynomial basics)

Question 1

A researcher models crop yield (continuous response) using rainfall (a numerical predictor) and fertilizer type (a categorical predictor with 3 levels). According to the note's classification of linear regression models by predictor types, this is a(n):

  1. General linear regression model
  2. Analysis of covariance (ANCOVA) model
  3. Analysis of variance (ANOVA) model
  4. Polynomial regression model

Answer: B.

Justification: The note classifies models by predictor type: all predictors numerical gives a general linear regression model, all predictors categorical gives an ANOVA model, and a mix of numerical and categorical predictors gives an ANCOVA model.

Why the others are wrong: A requires every predictor to be numerical, but fertilizer type is categorical. C requires every predictor to be categorical, but rainfall is numerical. D is defined by powers of a numerical predictor (x, x², x³, ...), which is not what this model describes.
Question 2

The note explains that the word linear in linear regression refers to linearity in the regression coefficients, not to a straight-line relationship between y and x. Consider the models: (i) y = β₀ + β₁x + β₂x² + ε; (ii) y = β₀ + 1/(β₁x₁ + β₂x₂) + β₃x₃ + ε; (iii) y = β₀ + β₁ln(x) + ε; (iv) y = β₀e^(β₁x) + ε. Which models are linear regression models in this sense?

  1. Only (i)
  2. (ii) and (iv)
  3. (i) and (iii)
  4. All four

Answer: C.

Justification: Model (i) is the note's own example (a quadratic polynomial model), and model (ii) is its example of a model that is not linear, because the β's do not enter linearly. Model (iii) is linear in β₀ and β₁ (ln(x) is just a transformed predictor), and model (iv) is not, because β₁ sits inside the exponent.

Why the others are wrong: A leaves out (iii), which is linear in its coefficients even though it is not a straight line in x. B selects exactly the two models whose coefficients enter nonlinearly. D includes the nonlinear models (ii) and (iv).
Question 3

The following model is fitted to the mtcars data. What is its polynomial degree, and what does the note's practical guideline say about it?

cubic_model <- lm(mpg ~ hp + I(hp^2) + I(hp^3), data = mtcars)
  1. Degree 3 (cubic); this is at the maximum degree the guideline suggests, so going higher should be avoided
  2. Degree 2; the guideline recommends at least degree 3
  3. Degree 3 (cubic); the guideline says polynomial models should never exceed degree 1
  4. Degree 4, because the model has four coefficients

Answer: A.

Justification: The degree is the highest power of x in the model, which is 3 here. The note recommends avoiding high-degree polynomials to keep the model interpretable and suggests limiting the degree to no more than 3.

Why the others are wrong: B miscounts the degree and reverses the guideline. C states a guideline that does not exist (degree 1 would just be a straight line). D confuses the number of coefficients (4, including the intercept) with the degree, which is the highest power (3).
Question 4

The note fits a quadratic model with the formula below. Why is hp^2 wrapped in I()?

quadratic_model <- lm(mpg ~ hp + I(hp^2), data = mtcars)
  1. I() centers hp before squaring it
  2. I() tells R to compute hp² arithmetically; inside a formula, the ^ symbol otherwise has a special meaning
  3. I() makes R treat hp as a categorical variable
  4. I() adds an interaction between hp and itself

Answer: B.

Justification: The note's code uses I(hp^2) for the squared term. In R model formulas, operators such as ^ describe how terms are combined, not arithmetic, so I() (as is) protects the calculation and makes R add a column equal to hp squared. (The note uses I() without explaining it; this is standard R behavior.)

Why the others are wrong: A is wrong because I() does no centering; centering would be written as hp - mean(hp). C is wrong because factor() is the function that creates a categorical variable. D is wrong because an interaction is written with : or *, and I() only protects an arithmetic expression.
Question 5

The note says that x, x², and x³ are often highly correlated in a polynomial regression model. What practical remedy does the note recommend?

  1. Convert x to a factor variable
  2. Center the predictor and use x − x̄, (x − x̄)², and (x − x̄)³
  3. Always add a higher-degree term
  4. Remove the response variable from the model

Answer: B.

Justification: Under the no-multicollinearity assumption, the note says we can center the predictor variable to reduce collinearity between the polynomial terms, using x − x̄, (x − x̄)², and (x − x̄)³ in place of x, x², and x³.

Why the others are wrong: A would discard the numerical information in x and turn the model into an ANOVA-type model. C makes the correlation problem worse and conflicts with the advice to keep the degree low. D is meaningless, since a regression model needs a response variable.

Part 2: Polynomial Regression (mtcars Example)

Question 6

The note first fits the first-order model lm(mpg ~ hp, data = mtcars). Its residuals-versus-fitted plot shows a clear curved pattern, and its Q–Q plot indicates a violation of normality. What does the note conclude?

  1. The first-order model is not the best choice, so higher-order polynomial models should be considered
  2. The first-order model is adequate, because R² = 0.6024 is above 0.5
  3. The data should be converted to a categorical variable and analyzed with ANOVA
  4. The residual plot has no useful information, so only the F test matters

Answer: A.

Justification: The note says the curved pattern in the residual plot and the normality violation show that the first-order linear model is not the best, and it then fits quadratic and cubic models.

Why the others are wrong: B treats a moderate R² as proof of validity, but validity is judged by the diagnostic plots. C changes the type of the predictor without any reason, because hp is numerical. D ignores the diagnostics, which are the basis for choosing the model.
Question 7

Here is part of the output for the first-order model. Which statement is correct?

Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) 30.09886    1.63392  18.421  < 2e-16 ***
hp          -0.06823    0.01012  -6.742 1.79e-07 ***

Residual standard error: 3.863 on 30 degrees of freedom
Multiple R-squared:  0.6024,    Adjusted R-squared:  0.5892
F-statistic: 45.46 on 1 and 30 DF,  p-value: 1.788e-07
  1. Each additional unit of horsepower is associated with an average increase of about 0.068 mpg
  2. The correlation between mpg and hp is 0.6024
  3. The slope is not significant, because the residual standard error (3.863) is large
  4. Each additional unit of horsepower is associated with an average decrease of about 0.068 mpg, and the correlation between mpg and hp is about −0.776

Answer: D.

Justification: The slope estimate is −0.06823 with p = 1.79e-07, so mpg decreases by about 0.068 per unit of hp. In a simple linear regression R² = r², so |r| = √0.6024 ≈ 0.776, and the negative slope gives r ≈ −0.776.

Why the others are wrong: A has the wrong sign. B confuses R² with the correlation coefficient r. C is wrong because significance comes from the p-value of the t test (1.79e-07), not from the size of the residual standard error.
Question 8

Here is part of the output for the quadratic model. Which conclusion is supported?

Coefficients:
              Estimate Std. Error t value Pr(>|t|)
(Intercept)  4.041e+01  2.741e+00  14.744 5.23e-15 ***
hp          -2.133e-01  3.488e-02  -6.115 1.16e-06 ***
I(hp^2)      4.208e-04  9.844e-05   4.275 0.000189 ***

Residual standard error: 3.077 on 29 degrees of freedom
Multiple R-squared:  0.7561,    Adjusted R-squared:  0.7393
F-statistic: 44.95 on 2 and 29 DF,  p-value: 1.301e-09
  1. The quadratic term is not significant, so the model should be reduced to the straight line
  2. The F test (p = 1.301e-09) shows that every coefficient is individually significant
  3. The residual df is 30, the same as the first-order model, because both models use the same data
  4. The quadratic term is significant (p = 0.000189), so the curvature is supported; R² rises from 0.6024 to 0.7561, and the residual df is 29

Answer: D.

Justification: The t test for I(hp^2) has p = 0.000189 < 0.05, and R² increases from 0.6024 to 0.7561 (the note calls the quadratic model much better). With n = 32 observations and 3 estimated coefficients, the residual df is 32 − 3 = 29.

Why the others are wrong: A reads the output backwards: 0.000189 is far below 0.05. B misreads the F test, which tests all slopes together, not each coefficient. C is wrong because each extra coefficient uses up one df (30 for the linear model, 29 for the quadratic).
Question 9

A student uses the rounded coefficients of the quadratic model to predict mpg for a car with 100 horsepower (the hp values in the data range from 52 to 335). Which statement is correct?

> 40.41 - 0.2133*100 + 0.0004208*100^2
[1] 23.288

Which statement is correct?

  1. The prediction is about 19.2 mpg (the student should use 2×hp in place of hp²)
  2. The prediction is about 40.4 mpg, the intercept, because hp has a negative coefficient
  3. The prediction is about 23.3 mpg, and since hp = 100 is inside the observed range, this is an interpolation
  4. The prediction is about 65.9 mpg, found by adding the absolute values of the three coefficient terms

Answer: C.

Justification: Substituting into mpg = 40.41 − 0.2133·hp + 0.0004208·hp² gives 40.41 − 21.33 + 4.208 = 23.288 ≈ 23.3 mpg. Since 52 ≤ 100 ≤ 335, the prediction is within the observed range, which is where the note says predictions are meaningful.

Why the others are wrong: A replaces hp² with 2×hp, which is not what the model says. B ignores the other two terms. D flips the sign of the hp term, which gives 40.41 + 21.33 + 4.208 ≈ 65.9.
Question 10

Here is part of the cubic model output, together with the quadratic model's fit statistics (R² = 0.7561, adjusted R² = 0.7393, residual standard error = 3.077). Which decision does the evidence support?

Coefficients:
              Estimate Std. Error t value Pr(>|t|)
(Intercept)  4.422e+01  5.961e+00   7.419 4.43e-08 ***
hp          -2.945e-01  1.178e-01  -2.500   0.0185 *
I(hp^2)      9.115e-04  6.863e-04   1.328   0.1949
I(hp^3)     -8.701e-07  1.204e-06  -0.722   0.4760

Residual standard error: 3.103 on 28 degrees of freedom
Multiple R-squared:  0.7606,    Adjusted R-squared:  0.7349
F-statistic: 29.65 on 3 and 28 DF,  p-value: 7.769e-09
  1. Keep the cubic model, because it has the highest R²
  2. Keep the cubic model, because the hp term is significant (p = 0.0185)
  3. Keep the quadratic model: the hp² and hp³ terms are not significant (p = 0.1949 and 0.4760), R² improves by only about 0.6%, and adjusted R² and the residual standard error get worse (0.7349 and 3.103)
  4. Keep the cubic model, because its overall F test is significant

Answer: C.

Justification: The note compares R² = 0.7606 (cubic) with 0.7561 (quadratic), an improvement of about 0.6%, calls it insignificant, and stays with the quadratic model. The adjusted R² (0.7393 → 0.7349) and residual standard error (3.077 → 3.103) also move in the wrong direction, and neither added term is significant.

Why the others are wrong: A is wrong because R² never decreases when a term is added, so it cannot be used by itself to choose between nested models. B looks only at the hp term; a significant hp term says nothing about whether the extra hp² and hp³ terms are needed. D is wrong because the overall F test only shows that at least one slope is nonzero, which was already true for the quadratic model.
Question 11

In the cubic output above, the overall F test is highly significant (p = 7.769e-09), yet the t tests for I(hp^2) and I(hp^3) are not significant. Which is the best interpretation?

  1. The terms hp, hp², and hp³ are strongly correlated, so each adds little once the others are in the model. This is consistent with the multicollinearity the note warns about, and centering hp would reduce it
  2. The output must contain an error, because the F test and the t tests must always agree
  3. The F test is significant only because of the hp³ term
  4. Centering hp would change the fitted values and R² of the cubic model

Answer: A.

Justification: The note lists no multicollinearity as an assumption and says high-order terms are often highly correlated, which makes individual coefficients hard to estimate. The F test asks whether the three slopes are jointly zero, while each t test asks whether a term adds anything beyond the other terms, so the two can disagree. The note recommends centering to reduce the collinearity.

Why the others are wrong: B is wrong because the F test and the individual t tests answer different questions and need not agree. C is false: the hp³ term has p = 0.4760. D is false because centering is a re-expression of the same polynomial, which changes the coefficients and standard errors but not the fitted values or R².
Question 12

The note warns about the danger of extrapolation. The observed hp values range from 52 to 335. A student uses the quadratic model to predict mpg for a 500-horsepower car and gets about 39 mpg, more than the model predicts for a 100-horsepower car (23.3 mpg). What is the correct conclusion?

> 40.41 - 0.2133*500 + 0.0004208*500^2
[1] 38.96
  1. The prediction is an extrapolation outside the observed range; polynomial curves can behave erratically there, so the result should not be trusted
  2. The prediction is reliable, because the model has a high R² and a significant quadratic term
  3. The prediction shows that powerful cars are the most fuel efficient
  4. The problem is solved by switching to the cubic model

Answer: A.

Justification: The note says polynomials can behave erratically outside the observed x-range and gives the example of a model trained on adult heights and weights that predicts 148.142 pounds for a newborn 20 inches long. Here the fitted parabola turns upward after hp ≈ 253, so at hp = 500 it produces an implausible value.

Why the others are wrong: B confuses a good in-sample fit with good out-of-range prediction. C reads a mathematical artifact of the curve as a real effect. D is wrong because the cubic model is also a polynomial and has the same extrapolation problem.

Part 3: ANCOVA Model Structure

Question 13

An ANCOVA model has one numerical predictor X and a categorical predictor G with k = 4 levels, and it includes the interaction X × G. How many regression coefficients (including the intercept) does the model have, and why?

  1. 4, one for each level of G
  2. 8: the intercept, X, 3 dummy variables, and 3 interaction terms
  3. 6, because there are 4 + 2 variables
  4. 12, because every level of G needs its own intercept, slope, and error term

Answer: B.

Justification: For a factor with k levels the note defines k − 1 dummy variables (here 3) and k − 1 interaction terms X × G (here 3). Together with β₀ and β₁ this gives 1 + 1 + 3 + 3 = 8 coefficients, which is 2k.

Why the others are wrong: A ignores the numerical predictor, the intercept, and the interaction terms. C has no basis in the model structure. D counts an error term per group, but the model has a single error term ε ~ N(0, σ), and the reference level is absorbed into the intercept and slope.
Question 14

In the ANCOVA model Y = β₀ + β₁X + Σβᵢ Gᵢ + Σγᵢ(X × Gᵢ) + ε, what do βᵢ and γᵢ (i = 2, ..., k) represent, according to the note?

  1. βᵢ is the change in the slope for group i, and γᵢ is the shift in the intercept
  2. βᵢ is the slope of X for group i, and γᵢ is the intercept for group i
  3. Both βᵢ and γᵢ are random errors
  4. βᵢ is the shift in the intercept for group i, and γᵢ is the change in the slope of X for group i

Answer: D.

Justification: The note defines β₀ as the intercept for the reference group, β₁ as the slope of X for the reference group, βᵢ as the shift in intercept for group i, and γᵢ as the change in slope of X for group i.

Why the others are wrong: A swaps the two roles. B treats the coefficients as the group's own intercept and slope, but they are differences from the reference group. C confuses the coefficients with the error term ε.
Question 15

In the depression study, treatment A is the reference level and Z^B and Z^C are the dummy variables for treatments B and C. Which expression gives the regression line for treatment C?

  1. Y = β₀ + β₁X
  2. Y = (β₀ + β₂) + (β₁ + γ₁)X
  3. Y = (β₀ + β₃) + (β₁ + γ₂)X
  4. Y = (β₀ + γ₂) + (β₁ + β₃)X

Answer: C.

Justification: For treatment C, Z^B = 0 and Z^C = 1, so Y = β₀ + β₁X + β₃ + γ₂X = (β₀ + β₃) + (β₁ + γ₂)X, as in the note's Case III.

Why the others are wrong: A is the line for the reference treatment A (both dummies equal 0). B is the line for treatment B (Case II). D mixes up the roles: β coefficients shift intercepts and γ coefficients shift slopes.
Question 16

The note says R defines the full ANCOVA model internally and that the formula used in the code is y ~ X + G + X*G. In R, which statement about the model formulas is correct?

  1. y ~ x * z fits only the interaction, without main effects
  2. y ~ x + z fits lines with different slopes but the same intercept
  3. If z is coded 0/1, R always treats it as a factor automatically
  4. y ~ x * z is equivalent to y ~ x + z + x:z; dropping the x:z term gives parallel lines with different intercepts

Answer: D.

Justification: The note says that if the interaction is not significant, the effect of X is the same across groups (parallel lines, though intercepts may differ), which is exactly the model without the x:z term. In R, x * z expands to x + z + x:z.

Why the others are wrong: A is false because * includes the main effects as well. B reverses the situation: without the interaction, the slopes are equal and the intercepts differ. C is false, and the note stresses that numerically labeled categorical variables must be converted with factor(), or R will treat them as continuous.

Part 4: ANCOVA by Example (Depression Data)

Question 17

Here is the coefficient table of the ANCOVA fit lm(y ~ x * z, data = depression), with treatment A as the reference level. What is the estimated regression line for treatment B?

Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) 47.51559    3.82523  12.422 2.34e-13 ***
x            0.33051    0.08149   4.056 0.000328 ***
zB         -18.59739    5.41573  -3.434 0.001759 **
zC         -41.30421    5.08453  -8.124 4.56e-09 ***
x:zB         0.19318    0.11660   1.657 0.108001
x:zC         0.70288    0.10896   6.451 3.98e-07 ***
  1. y = −18.59739 + 0.19318x
  2. y = 28.9182 + 0.52369x
  3. y = 47.51559 + 0.52369x
  4. y = 28.9182 + 0.33051x

Answer: B.

Justification: For treatment B the intercept is β₀ + β₂ = 47.51559 − 18.59739 = 28.9182, and the slope is β₁ + γ₁ = 0.33051 + 0.19318 = 0.52369, which matches the line the note reports.

Why the others are wrong: A uses only the adjustment terms and leaves out the reference-group intercept and slope. C adds the slope shift but forgets the intercept shift. D adds the intercept shift but forgets the slope shift.
Question 18

Use the coefficient table from the previous question. Which statement about the interaction terms is correct at the 0.05 level?

  1. The x:zC term (p = 3.98e-07) shows that the slope for treatment C differs significantly from that of A (by about +0.70 per year), while the x:zB term (p = 0.108) gives no significant evidence that B's slope differs from A's
  2. Both interaction terms are significant, so all three slopes differ significantly
  3. The x:zB term is not significant, so there is no interaction in the model at all
  4. The x:zC term is significant only because the zC main effect is significant

Answer: A.

Justification: Each interaction coefficient γᵢ is the change in slope relative to the reference group A, and its t test checks whether that change is zero. The test for x:zC gives t = 6.451 and p = 3.98e-07, while x:zB gives t = 1.657 and p = 0.108 > 0.05.

Why the others are wrong: B overlooks that x:zB has p = 0.108. C is wrong because a significant x:zC term already shows that the effect of age depends on the treatment, so the interaction cannot be dropped. D is wrong because each coefficient has its own t test, and its significance does not come from the main-effect term.
Question 19

Using the three fitted lines from the depression data (A: 47.51559 + 0.33051x, B: 28.9182 + 0.52369x, C: 6.21138 + 1.03339x), where a higher y means a more effective treatment and x is age, which statement is correct? (Assume both ages are within the range of the data.)

  1. Treatment A has the highest predicted effectiveness at both age 30 and age 60
  2. The ordering of the three treatments is the same at every age, because the intercepts differ
  3. At age 30 treatment A is highest (about 57.4), but at age 60 treatment C is highest (about 68.2, versus 67.3 for A); the A and C lines cross near age 58.8, which reflects the interaction
  4. Treatment C is the least effective at every age, because its intercept is the smallest

Answer: C.

Justification: At age 30 the predicted values are A = 57.43, B = 44.63, C = 37.21. At age 60 they are A = 67.35, B = 60.34, C = 68.21. Setting the A and C lines equal gives x = 41.30421/0.70288 ≈ 58.8. The note explains that the interaction is reflected in the different slopes, which implies intersections between the regression lines.

Why the others are wrong: A fails at age 60, where C overtakes A. B is the opposite of what the interaction implies: when slopes differ, the ordering can change with age. D confuses the intercept (the value at x = 0) with the effect at the ages of interest; C has the steepest slope and is the highest at age 60.
Question 20

The bottom of the ANCOVA summary reports the output below. The data have n = 36 individuals. Which statement is correct?

Residual standard error: 3.925 on 30 degrees of freedom
Multiple R-squared:  0.9143,    Adjusted R-squared:  0.9001
F-statistic: 64.04 on 5 and 30 DF,  p-value: 4.264e-15
  1. The F test shows that all five coefficients are individually significant
  2. The residual df is 31, because n − 5 = 31
  3. R² = 0.9143 proves that the model assumptions are satisfied
  4. The F test (5 and 30 df, p = 4.264e-15) rejects H₀ that all five non-intercept coefficients are zero; R² = 0.9143 means about 91.4% of the variation in y is explained; and the residual df is 36 − 6 = 30

Answer: D.

Justification: The model has 6 coefficients (intercept, x, zB, zC, x:zB, x:zC), so the residual df is 36 − 6 = 30, and the F test has 6 − 1 = 5 numerator df. The tiny p-value rejects the hypothesis that all slopes and group effects are jointly zero, and R² is the proportion of variation in y explained by the model.

Why the others are wrong: A is wrong because the overall F test is a joint test, and in fact x:zB is not significant individually (p = 0.108). B miscounts the parameters, since the intercept must be counted as well. C is wrong because a high R² says nothing about the assumptions, which the note checks with residual plots.
