📄 A3-ready · Letter
📈 Polynomial Regression non‑linear trends
\[ y = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots + \beta_p x^p + \varepsilon,\quad \varepsilon \sim N(0,\sigma^2) \]
🔍 Key points: Linear in coefficients; degree \(p\) (≤3 recommended). Centering reduces multicollinearity: use \((x-\bar{x}), (x-\bar{x})^2\).
# Quadratic example (mtcars: mpg ~ hp + hp²) mtcars <- read.csv("https://pengdsci.github.io/STA200/dataset/mtcars.csv") quadratic_model <- lm(mpg ~ hp + I(hp^2), data = mtcars) summary(quadratic_model) # Centered polynomial to reduce collinearity mtcars$hp_c <- mtcars$hp - mean(mtcars$hp) quad_centered <- lm(mpg ~ hp_c + I(hp_c^2), data = mtcars)
🧪 Polynomial Diagnostics R², AIC, residual plots
\[ R^2 = 1-\frac{SS_{res}}{SS_{tot}}, \quad \text{adj-}R^2 = 1-\frac{(1-R^2)(n-1)}{n-p-1} \]
📌 Model comparison: Quadratic yields \(R^2 = 0.7561\), cubic improves only 0.59% → prefer simpler model.
# Residual diagnostic plots par(mfrow = c(2,2)) plot(quadratic_model) # check Residuals vs Fitted, Q-Q, Scale-Location # Compare models linear_model <- lm(mpg ~ hp, data = mtcars) anova(linear_model, quadratic_model) # F-test for improvement AIC(linear_model, quadratic_model)
📊 ANCOVA Model interaction & slopes
\[ Y = \beta_0 + \beta_1 X + \sum_{i=2}^{k}\beta_i G_i + \sum_{i=2}^{k}\gamma_i (X \times G_i) + \varepsilon \]
🧩 Interpretation: \( \beta_0\) baseline intercept, \(\beta_1\) baseline slope; \(\gamma_i\) slope change for group \(i\). Interaction => different regression lines per group.
# Depression dataset: treatment A, B, C with age covariate depression <- read.csv("https://pengdsci.github.io/STA200/dataset/depression.csv") # ANCOVA with interaction: y ~ x * z (equivalent to x + z + x:z) dep_ancova <- lm(y ~ x * z, data = depression) summary(dep_ancova) # Extract group-specific equations: # Treatment A (ref): y = 47.516 + 0.331*x # Treatment B: y = (47.516-18.597) + (0.331+0.193)*x # Treatment C: y = (47.516-41.304) + (0.331+0.703)*x
🔍 ANCOVA Diagnostics normality · homoscedasticity
\[ \text{Residuals} \sim N(0,\sigma^2),\quad \text{constant variance, independence} \]
📌 Assumptions: linearity, independent errors, homoscedasticity, normality. Check with residual plots.
par(mfrow = c(2,2)) plot(dep_ancova) # Residuals vs Fitted, Q-Q, Scale-Location, Leverage # Test for interaction significance: # p-value for x:zB = 0.108 (not significant), x:zC = 3.98e-07 (significant) # => slopes differ between A and C. # If interaction non-significant, fit additive model: dep_additive <- lm(y ~ x + z, data = depression) anova(dep_additive, dep_ancova) # test interaction effect
📏 Global F-test & R² inference for MLR
\[ H_0: \beta_1 = \beta_2 = \dots = \beta_p = 0, \quad F = \frac{MS_{reg}}{MS_{res}} \sim F_{p, n-p-1} \] \[ R^2 = \frac{SS_{reg}}{SS_{tot}},\quad \text{adj-}R^2 = 1 - \frac{(1-R^2)(n-1)}{n-p-1} \]
📈 Use F-statistic p-value to test overall model significance. Adjusted R² penalizes extra predictors.
summary(quadratic_model) # shows F-statistic, R², adj R² # Global F-test p-value: 1.301e-09 => model significant # For ANCOVA: summary(dep_ancova)$fstatistic # F = 64.04, p = 4.264e-15 → strong evidence that at least one β ≠ 0
⚖️ Centering Predictors reduce multicollinearity
\[ x_{\text{centered}} = x - \bar{x}, \quad \text{model: } y = \beta_0^* + \beta_1^*(x-\bar{x}) + \beta_2^*(x-\bar{x})^2 + \varepsilon \]
✨ Why: High correlation between \(x\) and \(x^2\) causes unstable estimates. Centering improves numerical stability and interpretability of lower-order terms.
# Centering before polynomial terms mtcars$hp_centered <- mtcars$hp - mean(mtcars$hp) model_centered <- lm(mpg ~ hp_centered + I(hp_centered^2), data = mtcars) summary(model_centered) # Check variance inflation: library(car); vif(model_centered)
🏷️ Factors in R categorical handling
\[ \text{dummy coding: } G_i = \begin{cases} 1 & \text{if level i} \\ 0 & \text{otherwise} \end{cases} \]
⚠️ Important: Numeric codes must be converted to factor to avoid being treated as continuous.
# Convert numeric treatment (1,2,3) to factor depression$z_factor <- factor(depression$z) ancova_proper <- lm(y ~ x + z_factor + x:z_factor, data = depression) # Check levels: baseline is first level (A) contrasts(depression$z_factor) # Equivalent simplified formula with '*' ancova_interaction <- lm(y ~ x * z_factor, data = depression) summary(ancova_interaction)
📐 ANCOVA: group lines intercept & slope shifts
\[ \text{Group A (ref): } \hat{y} = \hat{\beta}_0 + \hat{\beta}_1 X \] \[ \text{Group B: } \hat{y} = (\hat{\beta}_0+\hat{\beta}_2) + (\hat{\beta}_1+\hat{\gamma}_1)X \]
From depression output:
Treatment A: \( \hat{y} = 47.516 + 0.331x\)
Treatment C: \( \hat{y} = 6.211 + 1.033x\) → steeper slope.
p-value for x:zC < 0.001 ⇒ significant slope difference.
# Visualize fitted lines (using ggplot2-like base) plot(y ~ x, data = depression, col = as.factor(z), pch = 16) abline(a = 47.516, b = 0.331, col = "red", lwd = 2) # A abline(a = 28.918, b = 0.524, col = "blue", lwd = 2) # B abline(a = 6.211, b = 1.033, col = "forestgreen", lwd = 2) # C legend("topright", legend = c("A","B","C"), col = c("red","blue","forestgreen"), lwd = 2)
🧾 Residual diagnostics plot assumptions
\[ \text{Residuals } e_i = y_i - \hat{y}_i,\quad \text{Q-Q plot for normality} \]
✔️ Standard checks: Residuals vs Fitted (constant variance, no pattern), Q-Q (normality), Scale-Location (homoscedasticity), Residuals vs Leverage (influential points).
# Generic diagnostic function for any lm object diagnostic_plots <- function(model) { par(mfrow = c(2,2)) plot(model) # Look for: # - red line nearly horizontal (linearity) # - points along diagonal in Q-Q # - no fan shape in Scale-Location } diagnostic_plots(quadratic_model) diagnostic_plots(dep_ancova)
🧠 Best Practices MLR guidelines
\[ \text{Avoid extrapolation: } x_{\text{new}} \notin [\min(x),\max(x)] \]
📌 Summary: • Polynomial degree ≤ 3 • Center predictors for higher-order terms • Use ANCOVA to adjust for covariates • Check interaction significance • Keep models parsimonious (AIC / adj-R²) • Never extrapolate beyond data range.
