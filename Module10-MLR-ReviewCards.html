STA 200 STATISTICS II

📋 Multiple Linear Regression & ANOVA

Essential formulas & procedures from MLR / one-way / two-way ANOVA · binary & multi-category predictors
📈 SLR · Continuous predictor log-wage model
\[ \log(\text{wage}) = \beta_0 + \beta_1 \cdot \text{educ} + \varepsilon,\quad \varepsilon \sim N(0,\sigma^2) \]
Interpretation: \( \hat{\beta}_1 = 0.0827 \) → each year of education increases log-wage by 0.083 (p ≈ 0).
\(R^2 \approx 0.186\) weak linear correlation.
# fit SLR with log(wage) ~ education edu.wage = read.csv("https://pengdsci.github.io/STA200/dataset/EduWage.csv") lgw.model = lm(lwage ~ educ, data = edu.wage) summary(lgw.model) plot(lgw.model) # residual diagnostics: Q-Q, residuals vs fitted
✔️ Reviewed linearity & constant variance (residual plot)
🧬 Binary predictor · Two-sample t-test via regression dummy coding
\[ \log(\text{wage}) = \beta_0 + \beta_1 \cdot \text{smsa} + \varepsilon,\quad \text{smsa}=0(\text{rural}),1(\text{urban}) \] \[ \hat{\beta}_0 = 1.4518 \ (\text{mean log wage rural}),\quad \hat{\beta}_1=0.2373 \] Urban wage is \(e^{0.2373}\approx 1.268\) times rural → 26.78% higher.
smsa.lm = lm(lwage ~ factor(smsa), data = edu.wage) summary(smsa.lm) anova(smsa.lm) # F-test equals squared t-statistic # convert coefficients: exp(coef(smsa.lm)[2]) gives multiplier
📘 Understand baseline category & difference interpretation
🌾 One-way ANOVA → Regression approach k-1 dummies
\[ \text{weight} = \beta_0 + \beta_1 \cdot I_{\text{trt1}} + \beta_2 \cdot I_{\text{trt2}} + \varepsilon \] Baseline = "ctrl". \(\beta_0 = \mu_{ctrl}\), \(\beta_1 = \mu_{trt1}-\mu_{ctrl}\), \(\beta_2 = \mu_{trt2}-\mu_{ctrl}\)
F-test in ANOVA table: \(H_0: \beta_1=\beta_2=0\) same as one-way ANOVA.
plant = read.csv("https://pengdsci.github.io/STA200//dataset/oneWayPlantGrowth.csv") plant.lm = lm(weight ~ group, data = plant) summary(plant.lm) # coefficients: grouptrt1, grouptrt2 anova(plant.lm) # identical F = 4.846, p = 0.0159 TukeyHSD(aov(weight ~ group, data = plant))
✅ Recall: dummies avoid multicollinearity; intercept = reference mean
🌽 Two-way ANOVA · interaction model Crop × Fertilizer
\[ \text{Yield} = \beta_0 + \beta_{\text{Crop}} + \beta_{\text{Fert}} + \beta_{\text{interaction}} + \varepsilon \] Baseline: Corn + Blend X. Coefficients represent differences; interaction tests whether effect of fertilizer depends on crop.
crop.data = data.frame(...) # as in document crop.lm = lm(Yield ~ Crop * Fertilizer, data = crop.data) summary(crop.lm) anova(crop.lm) # three F-tests: Crop, Fertilizer, Crop:Fertilizer # model.matrix shows all dummy variables colnames(model.matrix(crop.lm))
🧪 Interaction term significance → p = 0.0688 (moderate)
🧩 Dummy variables & baseline selection k categories → k-1 dummies
For a categorical variable with \(k\) levels, define \(k-1\) binary indicators.
\[ \text{Dummy}_j = \begin{cases}1 & \text{if category = level}_j \\ 0 & \text{otherwise}\end{cases} \] Perfect multicollinearity if all \(k\) dummies included: \(D_1 + D_2 + \dots + D_k = 1\).
# R automatically creates dummies with factor() edu.wage$region = factor(edu.wage$region) lm(lwage ~ region, data = edu.wage) # change baseline: relevel(factor(region), ref = "south") # anova F-test tests overall region significance
📌 F-test in regression for categorical variable = global ANOVA test
🔍 Regression diagnostics residuals & influential points
Assumptions: Linearity, Normality of residuals (\(\varepsilon \sim N(0,\sigma^2)\)), Constant variance (homoscedasticity), No high leverage / influential points.
Diagnostic plots: Residuals vs Fitted, Q-Q plot, Scale-Location, Residuals vs Leverage (Cook's distance).
par(mfrow = c(2,2)) plot(lm_model) # 4 diagnostic plots # check constant variance: residuals vs fitted should have no funnel # normality: Q-Q points should follow diagonal line # influence: cook's distance < 1 generally safe
📊 Evaluate plots: outliers? heteroscedasticity? (see document example)
⚖️ t-test ↔ F-test equivalence binary predictor
For SLR with binary predictor: \(t_{df}^2 = F_{1,df}\).
\(t = 4.676 \Rightarrow t^2 = 21.86\) equals F-stat from ANOVA.
\(H_0: \beta_1 = 0\) identical to two-sample equal variance t-test.
# SLR with binary factor model_bin = lm(lwage ~ factor(smsa), data = edu.wage) summary(model_bin)$coefficients # t-test anova(model_bin) # F-test, same p-value
🎯 one-way ANOVA = special case of MLR with dummy variables
📐 Log-response interpretation percentage change
If model is \(\log(y) = \beta_0 + \beta_1 x + \varepsilon\):
A one-unit increase in \(x\) multiplies \(y\) by \(e^{\beta_1}\).
Approximate percent change: \(100 \times (e^{\beta_1} - 1)\%\).
Example: urban vs rural \(e^{0.2373} \approx 1.268\) → +26.8% higher wage.
coef_beta1 = 0.23732 percent_change = (exp(coef_beta1) - 1) * 100 # back-transform predicted log-wage to original scale: exp(predict(lm_model, newdata))
📈 Useful when variance stabilizes after log transformation
📋 ANOVA table from regression lm() vs aov()
The function \( \texttt{anova(lm.object)} \) returns sequential Type I ANOVA table. For one-way / two-way designs it matches classic ANOVA F-tests.
# Two-way ANOVA from linear model crop.aov = aov(Yield ~ Crop * Fertilizer, data = crop.data) summary(crop.aov) # same anova table as anova(crop.lm) # Post-hoc: Tukey HSD TukeyHSD(crop.aov) # regression coeffs provide pairwise differences vs baseline
📚 Extract both: anova(lm) and summary(aov) give identical F/p-values
📊 Model fit · \(R^2_{adj}\) & F-test multiple predictors
\[ R^2_{adj} = 1 - \frac{(1-R^2)(n-1)}{n-p-1},\quad F = \frac{(TSS-RSS)/p}{RSS/(n-p-1)} \] Global F-test: \(H_0: \beta_1=\dots=\beta_p=0\). Significant F indicates at least one predictor matters.
summary(mlr_model)$adj.r.squared # F-statistic appears at bottom of summary() # example: multiple linear regression with educ + exper mlr_ex = lm(lwage ~ educ + exper + tenure, data = edu.wage) summary(mlr_ex) # F and p-value for overall significance
📉 Adjusted R² penalizes extra predictors
🎯 Influential observations Cook's distance
Cook’s distance measures influence of each observation on fitted coefficients. \(D_i > \frac{4}{n}\) or visually > 0.5 suggests high influence. Leverage: \(h_{ii} > \frac{2p}{n}\).
plot(model, which = 4) # Cook's distance plot # identify high leverage points hatvalues(model) > (2 * length(coef(model))) / nrow(data) # influence measures influence.measures(model)
⚠️ Outliers can distort coefficients – check Residuals vs Leverage plot
🤝 Interaction effects product terms
Model: \(y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 (x_1 \cdot x_2) + \varepsilon\)
Interpretation: effect of \(x_1\) on \(y\) depends on \(x_2\). In two-way ANOVA, interaction indicates factor levels are not additive.
# Using Crop * Fertilizer notation expands to main effects + interaction lm(Yield ~ Crop * Fertilizer, data = crop.data) # explicit: lm(Yield ~ Crop + Fertilizer + Crop:Fertilizer) # check significance of interaction term (last group of coefficients)
🧬 p-value for interaction term → if >0.05, additive model may be sufficient
